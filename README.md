# hongyu2016.github.io
hexo 博客

## 启动命令
- 如果全局安装了hexo，直接在博客根目录下执行hexo server
- 如果没有全局安装hexo，需要在博客根目录下执行yarn hexo server

## 部署命令
- 如果全局安装了hexo，直接在博客根目录下执行hexo deploy
- 如果没有全局安装hexo，需要在博客根目录下执行yarn hexo deploy

## 新建文章
- 直接在博客根目录下执行hexo new "文章标题" 即可新建一篇文章
- 新建的文章会在source/_posts目录下

## 其他命令
- 生成静态文件：hexo generate 或 hexo g
- 清除缓存：hexo clean
- 部署到服务器：hexo deploy 或 hexo d
